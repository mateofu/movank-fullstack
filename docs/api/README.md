# Contrato HTTP

El contrato OpenAPI se añadirá al implementar la API. Documentará autenticación,
esquemas, errores, idempotencia y SSE para estos endpoints:

- `POST /v1/products`
- `POST /v1/sales`
- `POST /v1/sales/{id}/pay`
- `GET /v1/sales/{id}`
- `GET /v1/dashboard/today`
- `GET /v1/dashboard/stream`
