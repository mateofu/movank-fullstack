# Pruebas de integración

Aquí vivirán las pruebas que necesiten componentes reales o recorran la aplicación
completa. Las pruebas unitarias de Go vivirán junto a sus paquetes; las del frontend,
junto a su código. No se añaden pruebas artificiales de carpetas vacías.

La cobertura prevista está en [el plan](../../docs/roadmap.md). Cada comportamiento
crítico se probará al implementarlo, sin posponer toda la validación a la etapa 10.
